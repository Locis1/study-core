# Study Core

Study Core is a long-term full-stack learning project designed to strengthen my understanding of mathematics, algorithms, software engineering, and computer science by building everything from scratch.

The goal is not only to solve mathematical problems, but to understand how they work internally, implement them in different programming languages, expose them through APIs, and visualize them in an interactive web application.

## Tech Stack

### Frontend

* Angular
* TypeScript
* CSS

### Backend

* C (algorithms, low-level programming, networking, mathematical core)
* Java & Spring Boot (object-oriented design, REST APIs, backend architecture)

## Project Goals

* Learn computer science through practical projects
* Build my own HTTP server and backend services
* Understand algorithms instead of only using libraries
* Visualize mathematical concepts interactively
* Create reusable learning modules
* Prepare for university and professional software development

## Learning Approach

Each topic follows the same workflow:

1. Learn the theory.
2. Implement the algorithm.
3. Build a backend API.
4. Connect it to the Angular frontend.
5. Visualize the concept.
6. Solve interactive exercises.
7. Review and improve the implementation.
